    Individual Note quick reference

    One page — the two output boxes, the reference format, the four session types, and the risk line — meant to be open next to Remarkable, alongside DocAssist, while you're actually writing a note.

    Before anything else: a progress note is not a therapy note. Document progress toward the objective — not a transcript of everything discussed. Overly detailed personal disclosures can be subpoenaed and used against the client; they don't belong here.
    Second reminder: if a note doesn't reference a specific goal letter and objective number, it isn't documentation of treatment toward a plan — it's just a record that a conversation happened.

    Progress note, not therapy note

    • Ask: does this document progress toward the objective, or does it just repeat what she told me? If it's the second, leave it out.
    • Acknowledge clinical relevance without transcribing the disclosure — "client identified a trigger connected to a past event" not the details of the event itself.
    • This record can be subpoenaed. Anything written here beyond what's needed to show progress can end up used against the client, not for them.

    Two output boxes

    Describe Therapeutic Interventions Provided: what objective(s) you worked on and what you did in session — built from your Session Description plus auto-generated lines about which objectives were reviewed or assigned.
    Response — Intervention/Progress/Clinical Judgement: how the client responded, whether reviewed objectives were completed, what's next, and the risk & safety line — every note gets one, even if nothing is wrong.

    The reference format

    • Objective reference = Section + Goal Letter + Objective Number: "Objective 1A of Goal A of Section C" — the section is now included, so a bare "Goal A" no longer has to be disambiguated from memory.
    • It's still worth a glance that the section named actually matches where that goal lives, especially with similarly-named goals across sections.
    • "Objective(s) Reviewed" rows can be marked Completed; "Objective(s) Assigned Next" rows cannot — they haven't happened yet.

    Four session types

    • Working off ITP (Reviewing) — the default, routine session type.
    • Updating/Revising ITP — when the plan itself is changing, not just being worked.
    • First Meeting/Initial ITP — no "reviewed" objectives yet; only "assigned next."
    • Crisis Intervention — hides ITP reference fields entirely; today's note isn't measured against the existing plan.

    Risk & safety

    • Leave every risk checkbox unchecked and the note still generates: "No risk or safety concerns identified this session." That's a real clinical claim — only let it stand if it's true.
    • If something concerning happened, check "Concerns present" and write it out — a checkbox alone says nothing about what occurred.

    Common Individual Note mistakes, at a glance

    Every pitfall from this module, gathered in one place.

    Scope
    Writing it like a therapy transcript
    Documenting everything discussed, every disclosure, every backstory detail. This is part of the discoverable legal record — it can be subpoenaed and used against the client. Document progress toward the objective, not the session's full emotional content.
    Reference format
    Not double-checking the section on similarly-named goals
    The note now includes the section automatically ("Objective 1A of Goal A of Section C"), which fixes the old ambiguity — but if a client has goals with the same letter in more than one section, it's still worth a glance to confirm the right one generated.
    Session types
    Using "Reviewing" for a first meeting
    A first session has nothing to review yet. Use First Meeting/Initial ITP so the note doesn't claim progress that hasn't happened.
    Session description
    Letting the auto-text stand alone
    The generated line just says an objective was reviewed — your free text is what proves what actually happened in the room.
    Response
    Marking an objective "Completed" without evidence
    The checkbox generates a clean sentence either way. Only check it when your progress notes actually back it up.
    Risk & safety
    Leaving concerns unchecked out of habit
    The default line reassures a reviewer nothing is wrong. If something is, "Concerns present" plus real detail is the only way that shows up.
    Every note
    A note with no goal or objective reference at all
    Without a reference, the note reads as an unstructured conversation, not treatment toward a documented plan.

    Frequently asked questions

    The questions staff actually ask about writing Individual Notes, answered directly. Click each one.

    + Can I include everything the client told me in session?
    No — and this matters more than it might seem. A progress note is not a therapy note. It documents progress toward a specific objective, not a transcript of the session. These notes are part of the legal medical record and can be subpoenaed in court proceedings — a note full of extensive personal disclosures can end up used against the client, not for them. If something is clinically relevant, acknowledge it briefly and connect it to the objective; don't reproduce the disclosure itself.
    + What if a session touched on more than one goal?
    Add a row for each objective you reviewed or assigned — the tool supports multiple. Reference each one by its own goal letter and objective number.
    + Does selecting "Motivational Interviewing" or "CBT" write anything into the note?
    Not directly — those selections don't currently generate their own sentences. Pick whichever technique the session actually centered on for your own record; if it mattered clinically, say so in your free text too.
    + What if nothing eventful happened this session?
    Same rule as everywhere else in this training: "nothing eventful" is still information, if you say what it means. Client attended, engaged with the assigned objective, no new concerns — that's a complete, honest note.
    + Do I have to assign a new objective at the end of every session?
    No. If the client is still actively working the same objective, leave "Assigned Next" pointed at it, or blank if genuinely nothing changed. Don't invent a new one just to fill the field.
    + Why does Crisis Intervention hide the ITP reference fields entirely?
    A crisis note is documenting an acute event, not routine progress on the existing plan — the tool's own auto-text says as much: the client's original ITP goals aren't a reflection of the crisis note.
